# QPortall: план до запуска

Главная копия: https://claude.ai/artifact/LVgmxjx2wcVghfGA8dfqfr (документ, Vadim правит и комментирует там).
Правило: перед каждым шагом сверяться с планом, работать сверху вниз. Новое от Vadim сначала вписать сюда на своё место.

1. Ссылка клиенту на готовый сайт - сделано 01.11: письмо уходит само сразу после публикации (решение Vadim), на языке сайта; «Пауза отправки клиентам» копит письма, снятие паузы отправляет; WhatsApp - кнопкой. Живая проверка - после обновления скрипта
1б. WhatsApp клиенту сам (WhatsApp Business API от Meta): нужен бизнес-аккаунт Meta и отдельный номер; подготовить шаги для Vadim и стоимость
2. Лендинг: пересборка на новом шаблоне (тексты поправлены 01.11) - ждёт «пересобери лендинг»
3. Учёт бесплатного года (даты на «Сайты», письмо за месяц) и кредитов Netlify
4. Вычитка иврита и английского, убрать огласовки
5. Анкета на трёх языках - сделано 01.11 (RU/עב/EN, иврит справа налево, ссылка ?lang=he); письмо и WhatsApp клиенту на его языке - потом
6. Оплата: сравнение сервисов для Израиля - сделано 01.11, https://claude.ai/artifact/2qEJhByrQA2vGV8prhBoGL (совет: Morning + Grow, тариф Best); ждёт решения Vadim
7. Оплата: подключение (после осека, решение Vadim)
7б. Оплата на сайтах клиентов: кнопка «Оплатить» для мастеров без кассы и терминала (карта, bit, Apple Pay) - изучить самый простой надёжный вариант, сравнение с рекомендацией
8. Условия услуги для клиента (черновик)
9. Свой домен клиента
10. Финальная проверка всей цепочки (Android, iPhone/WebKit, компьютер, 3 языка)
11. Уборка: тестовые листы и сайты (с одобрения), старые проекты Google, 2FA
12. Короткая инструкция для Vadim
13. Search Console для лендинга

Ждёт Vadim: когда слать ссылку клиенту; «пересобери лендинг»; осек и платёжный сервис; цвета из брендбука; каналы рекламы; по желанию iPhone.
