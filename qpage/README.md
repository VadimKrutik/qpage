# QPage — универсальный шаблон одностраничного сайта (этап 1)

Статический сайт: HTML + CSS + JavaScript, без сборки, сервера и базы данных.
Языки: русский, иврит (справа налево), английский. Сейчас наполнен вымышленным
демо-бизнесом «Мастер Дом» (ремонт бытовой техники в Хайфе).

## Что где лежит

```
QPage/
  site/                  ← эта папка публикуется на Netlify целиком
    index.html           ← разметка всех 12 блоков
    assets/js/content.js ← ВСЕ данные и тексты сайта (менять только его)
    assets/js/app.js     ← логика: языки, блоки, форма, карта, QR
    assets/js/vendor/qrcode.min.js ← генератор QR (MIT, единственная библиотека)
    assets/css/style.css ← стили
    assets/img/          ← логотип и картинки (сейчас — рисунки-заглушки)
    _headers             ← заголовки безопасности для Netlify
    netlify.toml         ← настройки публикации (сборка не нужна)
  tests/                 ← автоматическая проверка (Node.js + Playwright)
  ПРОВЕРКА.md            ← итоги последней проверки
```

## Как сделать сайт для нового клиента

1. Скопировать папку `site`.
2. В `assets/js/content.js`:
   - `site.contacts` — телефон, WhatsApp, Telegram, почта (пустое значение убирает кнопку);
   - `site.map` — координаты; `text.*.map.address` — адрес на каждом языке;
   - `site.services`, `site.gallery` — цены и картинки; тексты к ним — в `text.ru/he/en` в том же порядке;
   - `site.blocks` — выключить ненужные блоки (`false`); блоки `credentials`, `pricelist`, `steps`,
     `video`, `reviews`, `accessibility` наоборот показываются только при `true`;
   - `site.theme` — цвета;
   - `site.demoNotice: false` — убрать плашку «демонстрационный сайт»;
   - `site.url` — рабочий адрес (для QR-кода).
3. Заменить `assets/img/logo.svg` и фотографии.
4. Проверить и опубликовать.

## Решения по умолчанию (можно поменять)

- **Данные** — в одном файле `content.js`, а не в JSON: так сайт открывается и двойным
  щелчком по `index.html`, без сервера. На этапе 3 этот файл будет генерироваться автоматически.
- **Адреса языков** — одна страница, язык в адресе: `?lang=ru`, `?lang=he`, `?lang=en`.
  Ссылку с нужным языком можно отправить клиенту; QR-код ведёт на текущий язык.
- **Язык по умолчанию**: язык из ссылки → ранее выбранный → язык браузера → русский.
- **Карта** — не грузится сама: сначала заглушка и ссылки на Google Maps и Waze,
  карта OpenStreetMap загружается только по кнопке (приватность, нет ключей и оплаты).
- **Шрифты** — системные, без Google Fonts: быстрее и без сторонних запросов.

## Форма обратной связи

`site.form.mode` в `content.js`:

- `"demo"` (сейчас) — ничего не отправляет и прямо пишет «Заявка НЕ отправлена».
- `"netlify"` — Netlify Forms: добавить `data-netlify="true"` к тегу `<form>` в `index.html`,
  опубликовать, включить уведомления в настройках Netlify.
- `"endpoint"` — POST JSON на `site.form.endpoint`; адрес нужно добавить в `connect-src` в `_headers`.

Сообщение «Заявка отправлена» показывается только если сервер ответил успехом.
После подключения отправки текст раздела «Конфиденциальность» нужно сверить с реальной обработкой данных.
